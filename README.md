## 🚀 Início Rápido

### Pré-requisitos

- Node.js 18+ instalado
- npm ou yarn

### Instalação

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar JSON Server (Terminal 1)
npm run server

# 3. Iniciar aplicação React (Terminal 2)
npm run dev
```
